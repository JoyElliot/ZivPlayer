# ADR 0012：媒体库、播放偏好与应用内资源

- 状态：Accepted
- 日期：2026-09-06
- 范围：个人设备功能补全；补充 ADR 0008、0009，保持 ADR 0002 的播放引擎边界

## 背景

初版已在用户的 Android 15 arm64 手机上验证单文件播放、轨道控制、字幕和历史续播。
本阶段补齐媒体库、设置、全屏、画中画和诊断，并准备更广的格式与运行稳定性验证。
用户将在下一次设备测试中确认效果；本轮实现和验证在主机完成，不启动或安装手机应用。
跨 API、ABI 和其他设备的扩展兼容矩阵按用户要求延后，公开发布仍不在本阶段范围内。

## 决定

### 状态、数据与授权

- `core:model` 定义有范围约束的播放选项、资源 ID 和可空诊断值；`core:media-api`
  定义媒体库、全局偏好、单媒体轨道偏好的接口。核心层不认识 Media3、Android URI 或 mpv 属性名。
- 一个进程级 `MediaRepositories` 持有同一个 Room 实例。v1→v2 增加文件夹、文件索引、
  轨道选择、外置字幕关联和资源表，保留原 `recent_media` 表、稳定 ID、唯一 URI 索引和 checkpoint。
  不使用破坏性迁移。损坏数据库的自动修复不属于此迁移。
- 一个 Preferences DataStore 保存全局设置。未知枚举、错误键类型、非法资源 ID 和越界值
  回退为受约束默认值；读取或写入故障通过界面/播放服务状态报告。
  应用级资源维护完成后才发出首次偏好值，覆盖仅启动播放服务的场景。
  资源选择与删除共用同一串行锁，写入前重新验证资源；界面即时反映后台播放/PiP 开关，
  偏好尚未加载时不自动进入画中画，离开 Activity 时先暂停。
- 媒体库与最近播放历史分开。添加文件夹和扫描只维护索引；实际打开文件时才登记历史。
  收藏、隐藏、名称/时间/大小排序及筛选属于索引状态，移除索引不会删除原文件。
- 文件夹使用 SAF 树授权。授权的取得、历史登记和回收共用串行锁；只要文件夹索引或历史记录
  仍引用一棵树，就保留其授权。判断依据为 Android 树 URI 身份，不推测文档 ID 的路径前缀。
- 扫描使用广度遍历、访问集合、扫描令牌以及目录/文档/结果/路径长度上限。
  失败或取消的部分扫描只合并已读结果，不删除尚未访问的旧索引；被移除根目录的旧扫描不能重建它。
  删除当前扫描目录会取消并等待任务收尾，删除与扫描共用协调锁，再检查并释放授权。
  查询有 15 秒超时，提供者使用独立的单线程、有界等待队列。忽略取消的提供者最多占住该工作线程，
  后续请求明确失败或等待，不持续创建工作线程。

### 字体、shader 和字幕

- 用户选取的字体、shader 和外置字幕先复制进应用私有目录，再作为独立资源登记。
  资源 ID 对种类与内容作 SHA-256，文件名不使用提供者名称；路径仅由受控目录和摘要组成。
- 单文件限制为字体 20 MiB、shader 2 MiB、字幕 8 MiB，总资源限制为 128 项/128 MiB。
  字体读取有界 SFNT 名称表；shader 要求 UTF-8 与 mpv HOOK 标记；字幕接受受支持的文本格式。
  这些检查不宣称能证明任意 GPU shader 的编译成功或视觉正确性。
- 资源导入以私有文件发布和 Room 登记作为提交点；启动/再次导入会清理未完成临时文件、
  丢失文件及过期引用。删除资源同时清理相关全局设置与字幕关联。
  媒体请求过期后已经完成的导入仍是可在设置中管理的资源，不能随意删除可能被其他媒体复用的副本。
- 外置字幕通过应用自己的 FileProvider 交给播放服务。借用的字幕 FD 随队列项保留，
  新媒体替换或引擎销毁后关闭；持久数据不保存 FD、mpv track ID 或 Media3 group ID。
- 音轨/字幕偏好按种类、语言、名称、编码和内外置属性匹配。内嵌轨道的相同特征可使用同类序号
  解歧；无法区分的外置轨道不自动猜选。字幕关闭状态单独保存。
- 新文件保持自动播放关闭，准备完成后先恢复私有字幕，再匹配轨道；轨道发现最多额外等待 2 秒，
  未匹配项通过状态消息说明并使用当前轨道。用户选择、新媒体、暂停或停止通过请求/意图代次使旧恢复失效。
  恢复的数据库/文件提供者读取不占用播放命令锁；暂停或停止同时唤醒尚在准备中的等待者。
  显式设置速度会取消该媒体尚未应用的默认速度。

### 播放配置、界面与诊断

- 应用通过 Media3 控制同一个服务。全屏和画中画复用一个可移动 Surface 内容，保持已有租约令牌机制。
  画中画要求实际视频轨道；窗口比例来自视频，范围遵守 Android 限制。
  远程播放按钮使用应用专属不可变 PendingIntent 与非导出接收器。
- 设置提供外观、续播、后台播放、常亮、自动画中画、默认速度、快进步长，以及解码、画质、适配、
  去隔行、色调映射、缓存、音画/字幕延迟、字幕样式、字体和有序 shader 链。
  默认速度在下一次媒体打开时使用；其余可变 mpv 选项通过平台适配层应用。
- mpv 名称和私有路径只存在于平台配置端口。初始化前应用完整配置；运行中只更改差异。
  某个 setter 失败时回滚包括该次尝试在内的属性；回滚失败暂停并发布 RESET，要求重建引擎。
- 诊断页可见且 Activity 已启动时每秒请求一次，服务同时最多处理一个诊断读取。
  字符串采用已有 JNI 原语观察，数值由可空属性读取；不把未取得的指标转换为零。
  诊断是异步收敛的观测，不是所有 mpv 属性的原子快照。
- JSON 导出保存明确的采样/导出时间和观测值，不包含媒体 URI、文件名或导入路径。
  导出目标由系统创建文档选择器返回，写入大小、时间和提供者工作队列均有上限。

### 运行容量与验证

- 原生事件进入 256 项有序队列。容量溢出会尽力暂停、保留触发事件代次并发布 RESET，
  后续事件不再进入已失效通道；不静默丢弃定位完成事件后继续播放。
- 历史记录通道容量为 512，观察协程使用挂起发送。媒体缓存和失败重试媒体数量有界，
  每个媒体只保留最新完成/重置对。重试采用新近顺序与公平轮转，单次重试有统一 2 秒预算；
  关闭时积压观察只更新有界状态，不对每条旧观察逐次等待慢数据库。
  超容量或超时会报告保存限制。这仍是 checkpoint 存储，不是不可丢失的事件日志。
- ADR 0008 的核心观察流及关闭尾部收集窗口仍有限；强制结束进程、永久 I/O 故障和极端积压
  不能保证每个历史过渡都落盘。协程时限也不是对不响应取消的原生调用的强制终止。
- 没有修改 23 项原生源码输入、6 项 JNI wrapper 输入或历史构建凭据。
  DataStore 引入的两个原生 shared-counter 库与 Compose 的两个 graphics helper 一起，
  按锁定 AAR 校验字节和 ELF/ZIP 16 KiB 对齐；libmpv 的 20 个凭据库及 16 个 JNI 方法继续核验。

## 后果

功能通过现有层次扩展，无须让特性界面依赖 Media3 或 mpv。
主机测试可以证明偏好边界、轨道指纹、迁移 SQL、回滚、队列容量和构建产物的一致性。
手机仍需验证真实 Room 升级、提供者授权、Surface/PiP 生命周期、跨进程轨道恢复、字体与 shader、
HDR/色彩、长时间播放和资源趋势。格式夹具在主机的成功解码只证明夹具有效，不替代 Android 播放验收。
