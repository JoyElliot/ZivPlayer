# ADR 0018：本地封面与媒体元数据

- 状态：Accepted
- 日期：2026-09-10
- 范围：补充 ADR 0012、0014 的媒体库与播放器显示；不改变播放记录或队列身份

## 背景

媒体库和音乐播放器此前只显示文件名与通用图标。用户要求视频、音乐封面及可读取的元数据，同时保留已有文件授权、播放历史、收藏和隐藏状态。

## 决定

- `core/media-api` 提供纯 Kotlin 的 `MediaDetails`、请求和仓库接口，缺失字段保持 `null`。Android 的检索、图片、URI 和缓存实现留在平台层。
- `LocalMediaDetailsStore` 使用现有可读 URI，通过 `MediaMetadataRetriever` 获取标签与内嵌图片。视频没有内嵌图片时提取接近片头的同步帧；`MediaExtractor` 补充编码、分辨率、采样率、声道等可读取字段。音乐不联网搜索封面。
- 只提取当前播放项目、已进入组合的媒体列表行和主动打开的详情；扫描仍只更新文件索引。元数据探测使用独立的单工作线程、有界队列和取消检查，单次请求连同等待最多 8 秒，不占用播放命令锁。服务的首次失败延迟后最多自动重试一次。
- 缓存位于 `cacheDir/media-details`，与数据库、用户资源和设置分开。来源 URI、文件名、MIME、大小、修改时间以结构化序列化后摘要作为磁盘身份；新请求提供的提示变化会使内存命中失效。内容读取时间单独保存，24 小时有效期不会被缓存访问时间续期。
- 图片最长边不超过 768 像素，JSON 与 JPEG 原子写入；读取时恢复 AtomicFile 备份，拒绝损坏或缺失的图片。磁盘按访问时间回收，目标上限为 64 MiB / 1024 个文件；内存详情最多 512 项，显示层图片缓存为 12 MiB。图片解码在线程池执行，画面按来源 URI 核对后显示，避免复用上一项图片。
- 封面用于媒体行、最近播放、迷你播放器和音乐播放页；音乐页显示标题、艺术家和专辑。媒体行更多菜单及播放页更多菜单提供“媒体信息”。详情显示文件中存在的字段，不把未知信息显示为零，也不由元数据改变原文件的排序、筛选或队列归属。
- Media3 的显示元数据从缓存投影。保留原始 `TOKEN`、`SEQUENCE` 与媒体 / 队列 ID，只附加只读来源信息并更新显示字段，不重新安装播放队列，不修改时间轴。元数据订阅和当前探测任务随播放服务结束而取消。
- 不增取或释放文件授权，不在探测时登记“最近播放”，不修改检查点、选轨、外挂字幕、收藏、隐藏或原文件。缓存可以随系统清理重新生成。

## 边界

Android 平台检索器对容器、编码和标签的支持与播放引擎不同；可播放但无法提取封面的文件仍使用通用图标。视频缩略图代表一个同步帧，不保证是章节封面或无黑场画面。编码字段描述已读取轨道，不能把不同轨道的缺失属性拼接成一条虚构轨道。

API 26 使用未缩放的同步帧 API 后缩小；API 27 起请求缩放帧。具体设备验证见 [2026-09-10 播放器完善记录](../validation/2026-09-10-player-completion.md)。
