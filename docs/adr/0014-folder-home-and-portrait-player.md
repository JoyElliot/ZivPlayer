# ADR 0014：文件夹列表首页与统一横竖屏播放器

- 状态：Accepted
- 日期：2026-09-08
- 范围：替代 ADR 0009 的纵向播放面板，更新 ADR 0013 的首页与双击交互

## 背景

原首页将文件操作、文件夹管理、筛选和排序排列成大按钮，竖屏播放仍是可滚动的功能面板。
用户提供了两张主流本地播放器的文件夹首页参考，要求文件列表成为主体，重做竖屏播放并完善手势。

## 决定

- 首页使用标题与搜索/排序/更多入口、分类标签、文件夹列表及固定在底部的迷你播放条。
  文件夹行显示名称、可见视频/音频数量与来源路径；媒体行显示文件名、大小及独立的更多操作。
  添加文件夹、打开文件、来源管理、隐藏项目、最近播放和设置在菜单中可达。
- 文件夹由已有 SAF 索引按 `(folderId, relativePath 的父路径)` 派生；同名目录保持独立。
  授权根内的直属媒体归入根目录；无媒体的授权根保持可见，支持重新扫描与移除索引。
  计数来自当前可见索引，不使用包含隐藏项的持久化 `mediaCount` 冒充可见文件数。
  没有新增全盘存储权限，也不展示无法从现有授权取得的容量、封面或时长。
- 搜索与排序后的目录内列表、全库列表分别构成点击播放/播放全部的队列快照，沿用服务的 500 项限制。
  当前列表超过 500 项时，单项点击直接打开该文件；播放全部仍由服务入口明确提示数量限制，不静默截断。
  扫描、收藏、隐藏和历史持久化规则不变。返回媒体库保留浏览位置与筛选状态。
  异步文件夹索引首次加载前不清除恢复的目录；加载完成后才处理已移除的来源。
- 横竖屏复用 `FullscreenPlayerScreen` 与服务中的播放会话；播放器没有底部页面导航和纵向表单。
  竖屏提供顶部返回/标题/更多、居中播放操作、底部时间轴及锁定/倍速/适配/队列/旋转入口。
  返回退出播放器至媒体库；旋转入口单独控制横屏。最近播放移到独立列表页面。
  控制层按扣除安全边距和内容边距后的同一宽度判定紧凑布局，避免临界宽度同时隐藏两处播放控件。
  使用 `TextureView` 将视频与控制层放在同一窗口合成路径，横竖屏与 PiP 继续移动同一个显示节点，
  沿用 direct Surface 和现有 token/lease，旋转不重建 VO，并保留系统原有转屏动画。
  视频缓冲区按视频宽高比设置固定分辨率，长边参考当前显示设备，横竖旋转不改变原生输出几何。
  显示比例优先取已选视频轨，贯通 mpv 的像素比例和旋转角度至 Media3 Format；
  90/270 度旋转交换显示宽高，缺失或无效元数据回退到 16:9。
  宿主 View 分别按适应、裁剪填充、拉伸布局 TextureView；窗口变化只调整显示区域，避免 EGL 新旧尺寸缓冲区交替显示。
  `setDefaultBufferSize` 与原生 `android-surface-size` 使用同一固定尺寸；后者通过 producer 设置覆盖消费端默认值，
  依据 [ANativeWindow 缓冲区尺寸契约](https://developer.android.com/ndk/reference/group/a-native-window#anativewindow_setbuffersgeometry)。
  首次连接或视频宽高比变化时，按实际纹理更新回调追加两次重绘，暂停时也能完成。
  后端重新应用当前 `window-scale`：锁定 mpv 将此选项标为 `force_update`，同值也走 VO 重绘；
  选项值、播放状态与进度命令均不改变，不重新加载媒体或临时恢复播放。
- 双击左侧三分之一后退 5 秒，右侧三分之一快进 5 秒，中间三分之一暂停/继续。
  双击步长固定为本次明确要求的 5 秒，不修改其他定位命令的全局步长。
  目标限制在已知媒体时长内；不支持定位时，侧边双击不会改成暂停。
  同一媒体的定位/速度能力更新不打断双击识别；媒体切换清除旧的跳转反馈。
- 单击显隐控制，横滑预览进度并在松手时提交一次；左侧竖滑调整播放器窗口亮度，右侧竖滑调整播放器音量。
  方向在越过触摸阈值后确定，单次滑动不会同时调整进度与音量/亮度。
  保留长按临时 2 倍速及按住横滑 0.25–4 倍速、取消/媒体切换/失焦恢复机制。
  锁定与弹层阻断视频手势；字幕、音轨、画中画、打开文件和停止在快捷菜单可达。
- 亮度只使用 Activity 的窗口覆盖值；返回媒体库或进入 PiP 时恢复原窗口亮度。
  不请求修改系统设置权限，不写全局亮度设置。

## 验证边界

JVM 覆盖目录分组身份、队列归属、双击区域/边界和竖滑数值策略。
Compose 设备用例覆盖真实指针流、互斥/取消/锁定、列表选择、导航和 Surface/PiP 回归。
暂停旋转同时比较直接读取的原生纹理帧与屏幕上的画面位置，连续录屏检查转屏过程；单张稳定截图不能替代过渡验收。
本轮 Android 15 真机范围见验证记录；TextureView 的合成功耗、HDR 表现、其他设备、大字体和特殊刘海仍需更完整矩阵。
字幕由 mpv 合成在视频缓冲区内；填充模式会一起裁剪视频和字幕，复杂 ASS 与外部黑边字幕布局不在本轮覆盖范围。
