# ADR 0019：仿飞书风格首页与玻璃底部导航

- 状态：已接受
- 日期：2026-09-26
- 基线：远端 `main` 的 `***`
- 范围：Android 媒体库、最近播放、设置及迷你播放条

## 背景

用户要求参考 `fang-feishu-app-class2-group1` 的 Android 界面重构首页和底栏，并明确开发阶段暂不考虑旧 Android 系统兼容性。

参考项目的实际主界面使用大标题、搜索入口、圆角列表和悬浮胶囊底栏。原 ZivPlayer 首页只有迷你播放条，最近播放和设置需要从更多菜单进入。本次保留文件夹优先的播放器信息架构，将视频和音频分为独立媒体页，连同最近播放与设置作为四个一级导航。

## 决定

- 底栏提供视频、音频、最近播放、设置四个入口。选中状态具有 Tab 语义，胶囊使用弹簧位移动画。视频和音频分别按媒体类型限定目录内容、搜索、收藏和播放队列，并保存各自的目录、筛选和搜索状态，以及最近播放滚动位置和设置展开状态。
- 迷你播放条移到共享导航容器，四个页面均可返回当前播放、暂停或查看队列。从播放器返回进入前的页面；全屏和画中画保持独立，不展示首页导航。
- 大标题、蓝色搜索/分类控件、圆角列表行及图标容器统一进入设计系统。主色参考 Android 客户端的 `#3482FF`，保留跟随系统、浅色和深色选项。状态栏和系统导航栏的图标明暗跟随应用实际背景，避免应用深色与系统浅色不一致时无法辨认。
- 通过 MIUIX `miuix-blur-android:0.9.3` 捕获页面背景。底栏、选中胶囊和迷你播放条采样这一背景层，应用实时模糊、圆角边缘折射与高光。玻璃层本身不进入捕获层，避免递归采样。
- 折射 shader 由本项目实现，按实际降采样比例转换所有几何量，并对边缘法线和平方根作数值边界保护。动效只影响显示，导航状态和业务回调仍由应用持有。
- 页面内容延伸到底栏后方，列表的 `contentPadding` 使用底部区域的实际测量高度；设置滚动区域使用同一留白。系统导航栏、横向安全区和输入法由外层统一消费，页面仅补剩余 inset，避免固定高度遮挡最后一项。
- 开发应用、三个 UI 功能模块和设计系统的 `minSdk` 调整到 33（Android 13）。本次不实现 API 26–32 的视觉降级，替代 ADR 0001/0003 中应用最低版本的初始决定。底层数据、播放模块和原生产物的兼容基线保持原样。
- 依赖新增只包含 MIUIX blur 0.9.3，更新受影响模块的锁文件和 SHA-256 校验元数据。播放引擎、原生库、SAF 授权、数据库、队列容量及播放请求处理不属于本次改动。

## 验证

主机检查、独立预览包的设备验证及明确边界记录在 [本轮验证记录](../validation/2026-09-26-home-glass-navigation.md)。参考项目用来确定视觉方向，不复制其业务页面、身份信息或应用资源。
