# ADR 0019：仿飞书风格首页与玻璃底部导航

- 状态：已接受
- 日期：2026-09-26
- 基线：远端 `main` 的 `***`
- 范围：Android 媒体库、队列和播放历史、设置及迷你播放条

> 2026-10-18：播放器连续展示和全局控件视觉由 [ADR 0021](0021-continuous-player-presentation.md) 更新；本记录保留当时的导航与信息架构决定。
> 后续 [ADR 0022](0022-selectable-home-dock.md) 恢复本记录的玻璃底栏为默认外观，保留简洁方案，并接入共同的连续视频层。

## 背景

用户要求参考 `fang-feishu-app-class2-group1` 的 Android 界面重构首页和底栏，并明确开发阶段暂不考虑旧 Android 系统兼容性。

参考项目的实际主界面使用大标题、搜索入口、圆角列表和悬浮胶囊底栏。原 ZivPlayer 首页只有迷你播放条，最近播放和设置需要从更多菜单进入。本次保留文件夹优先的播放器信息架构，将视频和音频分为独立媒体页，连同队列与设置作为四个一级导航。

## 决定

- 底栏提供视频、音频、队列、设置四个入口，选中状态具有 Tab 语义。视频和音频分别按媒体类型限定目录内容、搜索、收藏和播放队列，并保存各自的目录、筛选和搜索状态，以及队列滚动位置和设置展开状态。
- 队列页使用同一个滚动列表，上方为当前播放列表，下方为播放历史；点击队列条目沿用从头播放语义并留在队列页，历史保留续播和移除记录操作。断开连接时队列选择禁用。
- 四个主页按视频、音频、队列、设置的顺序放在同一横向 Pager 内，固定页面键并保留全部四页组合。视频/音频各自的异步列表投影、目录、筛选、搜索及滚动位置不因切换 Tab 而销毁；索引或筛选真实变化时仍按原规则重新计算，禁止播放过期投影。参考项目 `8676095d` 的 `ui/pager/MainPagerState.kt`，底栏点击按页距使用 300/400/500 ms 连续像素滚动，跨三页完整经过中间两页，不使用远距离预跳。内容区域允许左右拖动，底部玻璃和播放卡片保持悬浮位置。
- 程序切页期间底栏选中目标页；手指接管后跟随 Pager 当前页，选中同步不会回送点击。新导航取消旧导航，并按请求代次阻止旧协程覆盖新目标；未完成的目标随保存状态恢复。两种媒体页分别登记返回操作，返回键仅调用当前页；离屏弹窗关闭，诊断仅在设置诊断页停稳且主页可见时启用。
- 播放器和 PiP 覆盖主页时保留主页组合，但不放置、绘制或暴露其点击/无障碍内容，清除输入焦点并关闭主页弹窗；返回时继续使用已有投影和滚动位置。媒体行按实际来源页登记播放器返回位置。四页只复用既有 ViewModel 数据，没有新增扫描、数据库订阅或页面轮询；完整保活会保留各页 UI 内存及相关状态更新。
- 导航保留最初液态组件的完整胶囊、64 dp 高度、两侧 32 dp 边距、最大 480 dp 宽度和原始底部位置。存在当前媒体时，独立的播放卡片从上方包住原导航，与原导航等宽，两侧边线在导航 50% 高度的中线处接合，不绘制底边和下半圈；上方容纳普通字号 48 dp 的播放信息。外壳和播放信息直接读取原导航的弹簧动画：横向跟随面板微移，并与导航围绕同一个中心同比缩放；播放信息不再单独上移或内部位移，取消和释放也共用同一回弹。没有额外手势或独立的跟随动画时钟。普通状态点击区止于导航顶边，大字号仅使上方信息区域增高。右侧只保留播放/暂停，按钮触摸目标为 48 dp，按压反馈限制在内部 36 dp 圆内，队列由第三个 Tab 进入。四个页面均可返回当前播放。从播放器返回进入前的页面；全屏和画中画保持独立，不展示首页导航。
- 大标题、蓝色搜索/分类控件、圆角列表行及图标容器统一进入设计系统。主色参考 Android 客户端的 `#3482FF`，保留跟随系统、浅色和深色选项。状态栏和系统导航栏的图标明暗跟随应用实际背景，避免应用深色与系统浅色不一致时无法辨认。
- 通过 MIUIX `miuix-blur-android:0.9.3` 捕获页面背景。外层播放卡片、原导航胶囊和选中胶囊分别采样这一背景层，应用实时模糊、圆角边缘折射与高光。玻璃层本身不进入捕获层，避免递归采样。
- 底栏直接移植参考项目 `8676095d` 的 Apache-2.0 液态玻璃组件及其 Kyant0/AndroidLiquidGlass 改编层：点击按距离使用 300/400/500 ms 滑移；按住 160 ms 或横向超过 8 dp 进入跟手；胶囊按 78/56 倍弹性放大并按速度形变，松手收缩。底栏面板轻微橡皮筋位移；图标文字通过独立的着色捕获层放大 1.18 倍并参与折射、色散及动态高光。
- 捕获着色图标的隐藏层不包含最终指示器，也不暴露额外点击语义。外部页面选择只同步指示器，不合成点击回调；点击已选 Tab 仍执行应用回调，以便从诊断页返回设置。取消拖动恢复原选项和形状，不提交页面切换。
- 导航折射 shader 保留参考项目算法，按实际降采样比例转换几何量，补充采样留白、法线及平方根保护；外层卡片使用上方 20 dp 圆角，单独绘制开放的顶边和两侧高光；视频预览为 56 × 32 dp、12 dp 圆角，与外壳保持 8 dp 内距，播放信息横向内距收至导航内侧 8 dp；指示器继续使用原圆形镜片和倾斜高光，进度嵌入外层卡片顶部圆角描边，不参与布局高度。移植文件保留版权和修改声明，Apache-2.0 正文及来源通知随 APK 打包。
- 播放浮卡从当前控制器媒体项获取源 URI，在 IO 线程提取至多 320 × 180 的视频帧并使用 4 MiB 内存缓存；按媒体身份更换加载器，不随进度 ticker 重新解码。失效权限、不可读 URI 或平台不支持的编码显示占位图，音频继续使用音符图标；不改变原生播放链路。
- 页面内容延伸到底栏后方，列表的 `contentPadding` 使用底部区域的实际测量高度；设置滚动区域使用同一留白。系统导航栏、横向安全区和输入法由外层统一消费，页面仅补剩余 inset，避免固定高度遮挡最后一项。
- 开发应用、三个 UI 功能模块和设计系统的 `minSdk` 调整到 33（Android 13）。本次不实现 API 26–32 的视觉降级，替代 ADR 0001/0003 中应用最低版本的初始决定。底层数据、播放模块和原生产物的兼容基线保持原样。
- 依赖新增只包含 MIUIX blur 0.9.3，更新受影响模块的锁文件和 SHA-256 校验元数据。播放引擎、原生库、SAF 授权、数据库、队列容量及播放请求处理不属于本次改动。

## 验证

主机检查、独立预览包的设备验证及明确边界记录在 [本轮验证记录](../validation/2026-09-26-home-glass-navigation.md)。底栏需验证点击及按住过程中的中间帧、手指跟随、释放、取消、快速反向切换及 RTL，静态截图和最终选中状态不足以证明液态交互已复刻。
