# ADR 0013：播放交互与文件夹播放列表

- 状态：Accepted
- 日期：2026-09-07
- 范围：全屏播放页、快捷菜单、手势、当前播放列表和按文件夹浏览的首页

## 背景

单文件播放、轨道、字幕、媒体库和播放偏好已经具备真实实现，但界面仍以纵向功能面板为主。
本阶段按用户要求优先完善全屏播放和快捷操作，再把媒体库的文件夹与播放列表接通。
沿用现有 Kotlin / Compose / MIUIX 设计系统和服务持有的唯一 libmpv 实例。

## 交互决定

- 全屏以视频为主体。顶栏提供返回、媒体标题及快捷菜单；底部提供时间轴和播放操作。
  播放期间无操作后隐藏控制层；暂停、错误、菜单展开和操作期间保持可见。
  根据用户提供的 MX Player 布局参考，采用紧凑单行标题、音轨/字幕入口、细时间轴、居中上一项/播放/下一项，
  左侧锁定/倍率、右侧适配/队列。窄窗口将底部操作分成两行，保留触摸区域。
  快捷菜单和队列使用同一右侧抽屉；倍速集中显示为九宫格。图标由项目绘制，不引入参考应用资源。
  锁定后只保留可唤出的解锁入口，双击、横滑和长按均停止响应。
- 单击视频切换控制层；双击暂停或继续。按钮、时间轴和菜单自行处理触摸，不触发视频手势。
- 普通横滑从手势开始时的位置计算预览，松手仅提交一次定位；取消、多指干扰和媒体切换不提交。
  整屏滑动最多对应两分钟，短媒体按自身时长缩放，目标限制在媒体时长内。
- 长按播放中的视频临时切到 2 倍速；继续水平滑动按 0.25 倍步长调整，范围 0.25–4 倍。
  松手、取消、离开页面或失去播放前提时结束临时操作。临时倍率不写入全局默认速度。
  恢复必须受媒体和操作身份约束，不能用旧操作覆盖新媒体或用户后来选择的速度。
- 快捷菜单直接选择倍速、音轨、字幕和画面适配，并提供导入字幕、音量及循环等常用操作。
  全屏里的选择不要求退出全屏或跳转到完整设置页；普通播放页复用同一套菜单内容。
- 首页按文件夹组织已有 SAF 索引，保留搜索、排序、收藏与隐藏。播放列表由明确选择的媒体组成，
  使用独立队列项身份；文件夹扫描本身不代表播放，也不得把未播放项目写成已观看记录。
- 当前播放列表支持查看、切换、上一项/下一项和结束后顺序播放。服务仍是后台播放和媒体状态的所有者，
  不能依赖可见界面收到完成事件后再打开下一项。

## 所有权与持久化

- Media3 适配层保留每个队列出现位置的独立 ID 与原始元数据。文件夹内的“播放全部”和单项点击
  使用当前筛选、排序后的列表快照，最多 500 项；不会在扫描结果更新时暗中替换正在播放的列表。
- Media3 的列表编辑会先更新控制器的预览状态，因此添加、移动、替换、删除、完整替换和跨项定位
  在服务内按到达顺序等待前一项实际完成，再对 core 权威队列计算索引。不能在回调入口缓存旧列表。
  core 的 `EditQueue` 只接受完整保留当前队列项的编辑，不重新加载媒体、重置进度或改变播放意图。
  删除当前项走服务的准备/恢复流程；清空队列停止媒体并释放资源。RESET 错误先重建引擎。
  完整替换有独立代际，使旧队列操作失效；暂停/停止取消播放意图，但不丢弃已接受的增量编辑。
  暂停/停止也保留已接受的完整替换，否则紧随其后的编辑会落到旧 core 队列；仅在当前请求仍由服务持有时
  续接安装票据，新的外部 SAF 预约仍使旧安装失效。安装始终保持暂停，不能恢复被取消的播放意图。
  播放与轨道准备在操作锁外等待队列完成，防止相互等待；自然结束也在队列编辑之后重新计算下一项。
- core 仍持有权威队列。跨项自然结束先发布已完成状态，再将推进委派给播放服务，服务负责恢复目标项
  的轨道偏好、外置字幕和默认速率后开始播放。用户的新打开、暂停或切换操作必须能取消尚未完成的推进。
  单曲循环保留核心原有的同项重载路径。
- libmpv backend 仅为当前内容 URI 延迟打开一个媒体 FD；原始 URI 保存在队列中。
  已确认 END_FILE 的停止、后续加载或成功销毁 native 实例后才关闭 FD。
  native 命令或事件泵失败不等同于确认停止；借用关系不确定时保留到成功销毁。
  自然结束后允许保留当前一个 FD，直到下一次加载、停止或关闭，资源不会随队列大小增长。
- 临时倍速由服务持有，绑定控制器、操作 token、引擎代际与队列项。松手、暂停、断连和媒体切换终止操作，
  显式选择的新倍速优先；已结束操作的延迟消息不能重新取得所有权。
- Room v3 以新增列区分稳定媒体身份索引与最近播放。文件夹队列通过已有树授权预登记隐藏身份，
  不新增独立文档授权、不变更旧记录时间或 checkpoint；实际进入播放后才提升为最近播放。
  取消队列不会删除旧身份、轨道偏好或续播数据，已有树授权按引用保守保留。
  v2 的全部既有历史行迁移为可见，数据库迁移不得重建或清空旧表。

## 验证边界

主机检查覆盖手势数值策略、取消/恢复规则、文件夹分组、队列与适配契约，并执行现有回归和构建检查。
设备验证覆盖实际触摸、全屏控制层与弹层、临时速度恢复、真实跨媒体转场以及 Surface/后台生命周期。
保留用户现有媒体和设置；音频焦点继续按本次会话要求跳过。主机通过不替代设备交互或公开发布验收。
