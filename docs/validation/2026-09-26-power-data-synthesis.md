## “在一个标准差以内”如何解读

1. 每个数值是整轮240秒稳态积分均值。样本SD用轮均值计算、分母n−1；241个逐秒点不是241次独立重复。CV=SD/均值。n=2的SD尤其不稳定，不能据此宣称极高精度。
2. 跨夜表同时计算 `|新均值−旧均值|/旧SD` 和 `/新SD`；各自不超过1才在相应参考SD内。两种参照可能给出不同结果，所以不只挑较大的SD。区间相交按 `|差|≤旧SD+新SD` 计算，**相交也不等于均值落在对方1SD内**。
3. 这些都是后验描述，不是置信区间、p值、统计等效或合并许可。即使理想正态总体，也只有约68.3%的观测落在真实均值±1个总体SD内；不能将其余约31.7%自动视为坏数据。本表使用的小样本均值/SD更不能保证该覆盖比例。[NIST 正态分布](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3661.htm)
4. 均值不确定度与轮间SD是不同问题；经典均值区间还包含样本量和t分位数。本数据存在时间顺序和环境差异，本报告不把简单SD带包装成95%置信区间。[NIST 均值置信区间](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)
5. 比引擎优劣时优先保留同一个完整块内的功率差，再看块间差值SD；不拿一方引擎的单腿SD直接判两引擎相同。配对/区组帮助控制部分环境变化，但本试验顺序固定，不冒称随机试验，也不认为所有混杂已消除。[NIST 配对观测](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)、[区组设计](https://www.itl.nist.gov/div898/handbook/pri/section3/pri332.htm)

同夜重复性与跨日变异也需要区分：环境变化可能使跨日波动大于同夜SD，因此跨夜均值偏离不能一概当作测量错误。[NIST 测量过程变异](https://www.itl.nist.gov/div898/handbook/mpc/section1/mpc114.htm)

若要批准跨夜直接合并，应先有共同的分析目标和预设的实际可接受差异，再检查硬件/APK/素材/路径一致、资格、设计、环境层及跨夜差异的不确定度。本次小样本与温度/电量分布差异不足以给出该批准；不为了纳入旧数据事后放宽阈值。没有预设等效界限时，不能把“未看出差异”改写为“已证明等效”。
