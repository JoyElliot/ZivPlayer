# 2026-10-23：默认视频方向与同步旋转收起

## 范围

用户要求先同步已有提交，再让横视频打开时默认横屏、竖视频默认竖屏；横屏退出直接旋转缩到迷你条。随后明确要求同步到 `main` 并删除原分支。

## 实现

- 当前媒体准备就绪后，使用考虑像素比例、旋转元数据的有效显示比例决定默认方向。未知尺寸不会误用渲染回退比例；方形视频保留入口方向。每次打开、重新展开及队列更换可重新判断，手动方向优先。
- 首页、底栏和视频共享稳定逻辑画布。底栏安全区保留入口值，迷你槽位相对画布定位并跟随液态玻璃图层运动。保留默认液态玻璃及设置中的第二种底栏外观。
- 收起由同一进度驱动位置、大小和角度，达到迷你端点后再请求真实系统方向恢复。收起途中暂停旧旋转派发；打开动画和拖动期间也不提前提交窗口方向。
- 手指位移、触发阈值和速度统一按窗口坐标计算，处理旋转、缩放、移动中的触摸目标。收起过程中可重新拖动或点击展开。
- 返回操作单独取消尚未提交的手动 PiP，避免取消收起后仍进入 PiP。系统已经接受的 PiP 交接继续由原生命周期处理。
- 视频仍使用同一 `PlayerVideoSurface` 调用点；未切换播放核心、重建播放器或加入暂停指令。

方案见 [ADR 0023](../adr/0023-system-rotation-handoff.md)。此前用户确认无闪烁的是 `rotation4`；其真机结果保留在[上一份记录](2026-10-23-double-rotation-fix.md)，不替代本轮新路径的真机验收。
